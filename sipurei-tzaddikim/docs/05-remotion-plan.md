# תוכנית הרכבה ב־Remotion (תכנון בלבד — שום קוד לא הורץ)

## מה זה Remotion בקיצור
תוכנה שבונה סרטון מקוד. היתרון: אותו פרויקט מייצר גרסה בעברית וגרסה ביידיש רק על ידי החלפת הגדרה אחת.
**רישיון:** חינמי לאנשים פרטיים ולעסקים קטנים מאוד; לבדוק את תנאי הרישיון באתר remotion.dev לפני שימוש מסחרי.

## הגדרות
- 1920×1080, 30fps, 1800 פריימים (60 שניות)
- שתי גרסאות: `lang = "he"` ו־`lang = "yi"`

## מבנה תיקיות מתוכנן
```
remotion/
  public/
    video/shot01.mp4 ... shot06.mp4
    audio/he/  audio/yi/  audio/sfx/  audio/music/
    images/title_card.png
  src/
    Root.tsx          ← מגדיר שתי קומפוזיציות: Pilot-HE, Pilot-YI
    Pilot.tsx         ← מחבר את 6 השוטים ברצף
    Subtitles.tsx     ← כתוביות (עברית/יידיש, מימין לשמאל)
    shots.ts          ← טבלת תזמון השוטים
```

## טבלת תזמון (shots.ts)
| שוט | מפריים | אורך (פריימים) |
|---|---|---|
| 1 | 0 | 240 |
| 2 | 240 | 300 |
| 3 | 540 | 240 |
| 4 | 780 | 300 |
| 5 | 1080 | 300 |
| 6 | 1380 | 420 |

## מה כל רכיב עושה
- **Series** — מנגן את 6 הסרטונים אחד אחרי השני.
- **OffthreadVideo** — מציג כל קטע וידאו.
- **Audio** — קריינות לפי שפה + מוזיקה + אפקטים.
- **מעבר רך** (fade) של 10 פריימים בין שוטים.
- **שוטים 2 ו־5:** הנמכת המוזיקה לשקט.
- **שוט 6:** הקפאת תמונה, והכותרת "סיפורי צדיקים" נכנסת בשנייה 54.
- **כתוביות:** גופן עברי ברור, כיוון RTL.

## שלבים (כל שלב — רק אחרי אישורך)
1. התקנת Node.js ו־Remotion (חינם).
2. יצירת פרויקט ריק והעתקת המבנה.
3. הכנסת קבצים זמניים (תמונות סטילס) במקום הסרטונים — לבדוק תזמון.
4. החלפה לסרטונים האמיתיים.
5. רינדור: שתי גרסאות.
