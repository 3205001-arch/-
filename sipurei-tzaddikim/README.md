# סיפורי צדיקים — Tzaddik Stories

סדרת אנימציה לילדים בגילאי 5–9, בעברית וביידיש.

## פיילוט: נחום איש גם זו
סצנת ניסיון של 60 שניות: גילוי העפר בתיבה ואמירת "גם זו לטובה".
מקור: תלמוד בבלי, תענית כ״א ע״א.
